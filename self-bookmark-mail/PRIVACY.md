# Self Bookmark Mail プライバシーポリシー

最終更新日: 2026年8月13日

Self Bookmark Mail（以下「本拡張機能」）は、ユーザーが明示的に操作した場合に、現在表示しているWebページのタイトルおよびURLを、指定したメールアドレスへユーザー自身のGmailアカウントから送信するためのChrome拡張機能です

## 取得・利用する情報

本拡張機能は、機能提供のために以下の情報を取り扱います

- 送信先メールアドレス
- ユーザーが送信対象として選択したWebページのURLおよびページタイトル
- ユーザーが任意機能を有効にした場合、現在のページURLに一致するChromeブックマーク名
- Googleアカウントの認証に必要なOAuth情報
- メールの件名および本文としてGmail APIへ送信する情報

## 利用目的

取得した情報は、ユーザーが明示的に実行したメール送信機能およびその設定を提供する目的にのみ使用します

## 保存

送信先メールアドレスや一部の設定は、Chrome拡張機能のローカルストレージに保存されます

OAuthアクセストークンを本拡張機能独自のストレージへ保存しません。Google認証トークンはChrome Identity APIにより管理されます

## 第三者提供・販売

本拡張機能は、ユーザーデータを販売しません。また、本拡張機能の単一目的と無関係な目的で第三者へ提供または転送しません

メール送信のため、ユーザーの指示に基づきGoogleのGmail APIへ必要な情報を送信します

## 外部サーバー

開発者が運営する独自サーバーへ、ユーザーのWebページ情報、メール本文、認証情報を送信または保存しません

## 使用する権限

本拡張機能は、右クリックメニュー、Google認証、設定保存、送信結果通知、Gmail APIへの接続のために必要なChrome拡張機能権限を使用します

ブックマーク権限は、ユーザーがブックマーク名をメールタイトルに利用する任意機能を有効にした場合のみ使用します。ブックマークの作成、変更、削除は行いません

## Google API Services User Data Policy / Limited Use

本拡張機能によるGoogle APIから取得した情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います

取得した情報は、本拡張機能の明示された機能提供の目的にのみ使用し、広告、販売、信用評価、融資判断その他の無関係な目的には使用しません
